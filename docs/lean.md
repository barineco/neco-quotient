# Lean の定義と定理

観測による同値から証明書の照合と保持判定までを役割ごとのモジュールに分けて実装しています。標準ライブラリのみに依存します。

## モジュール

| モジュール | 内容 |
|---|---|
| `Observation` | 観測関数族に対する同値と商。関数を加えた商から元の商への粗視化と、既存の区別が保たれること |
| `Congruence` | 観測関数族の引き戻し、演算と演算族の合同、商の上の写像と可換図式 |
| `Bisimulation` | 一手の遷移系と双模倣。双模倣性が同値関係であること、関係にある二状態が同じ出力の列を返すこと |
| `BisimRule` | 二つの遷移系の双模倣を鍵で保証する規則。照合済みの証明書の鍵から出力列の一致を導くこと |
| `Judgment` | 符号の判定と線形順序上の区間。区間の包含に対する単調性と、点ごとの包含区間による精密化 |
| `Refinement` | 観測関数族の精密化。`VerifiedRefinement` が前後の入力参照、評価結果、証拠を結び付け、確定済み判定の保存を保証すること |
| `Blocks` | 領域の述語と代表値による類、有限の外延と区間による商、観測関数族を広げた類による細分 |
| `Certificate` | 入力参照、観測、証拠、射影ダイジェスト、残余集合の照合。受理条件と各条件の不一致の検出 |
| `RuleTable` | 規則をリビジョンごとに登録する型。リビジョンの不一致、未登録のリビジョン、規則がある場合の照合と、状態を持つ規則の射影ダイジェスト |
| `Resolver` | 外部入力の解決と照合。リビジョン、解決、照合を別の段階で扱い、受理時の入力参照と射影ダイジェストの対応を保証すること |
| `Retention` | 宣言された利用、観測、復元手段による保持判定。実体化解除、保持理由、入力不足の必要十分性 |
| `Guards` | 照合済みの値を作れるのが照合の関数だけであることの検査 |
| `Axioms` | 公開する定義と定理が依存する公理の一覧 |

`Bisimulation` と `BisimRule` は、遷移する二状態の観測と次状態の対応を証拠として表し、証明書の実行時照合では、その証拠と入力の対応を検査します。有限の入力に対する実行結果の一致は、その入力についての観測同値を示します。

## 照合の定理

`Certificate` モジュールの主な定理:

- `admit_sound`: 照合が成功したとき、結果は元の証明書、期待値、再計算結果を保持する
- `admit_complete`: 六つの一致条件が成り立てば、照合は成功する
- `admit_ok_iff`: 照合の成功と六つの一致条件は同値である
- `admit_provenance`: 失敗は呼び出し側が渡した来歴を保持する
